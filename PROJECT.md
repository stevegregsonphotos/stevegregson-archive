# Steve Gregson Archive
## Project Constitution

Last updated: August 2026

---

# Vision

Build the finest theatre photography website on the web.

Not simply another photographer portfolio.

The site should feel like an editorial publication, museum archive and luxury coffee-table book combined.

Every design decision should reinforce quality, longevity and trust.

The website must be:

- Fast
- Secure
- Search engine leading
- Beautiful
- Timeless
- Accessible
- Easy to maintain

Nothing should exist simply because "other websites do it."

---

# Core Principles

## Less but better.

Every line, colour, animation and interaction must justify its existence.

If removing something improves the page, remove it.

---

## Photography always leads.

Typography supports photography.

Interface never competes with photography.

---

## Editorial before portfolio.

The archive should feel like browsing an exhibition catalogue rather than scrolling a gallery of thumbnails.

---

## Timeless over fashionable.

Avoid trends.

Prefer restraint.

Design should still look contemporary in ten years.

# Golden Rule

Whenever making a design decision ask:

If the answer is no,

don't build it.

# Working Agreement

This section governs how development is carried out.

## Editing files

- Work on one file at a time.
- Never redesign existing sections unless explicitly requested.
- Small, iterative improvements are preferred over large rewrites.

When Steve pastes a source file:

- Return the COMPLETE modified file.
- Never return partial snippets unless specifically requested.
- Preserve formatting and existing code unless required by the requested change.

## Decision making

When proposing improvements:

- Explain why.
- Make one visual change at a time.
- Evaluate it together before moving on.

## Honesty

If a task cannot be completed because of a technical limitation, say so immediately.

Do not suggest that a completed file will be returned if it cannot be produced.

## Philosophy

The goal is not to finish quickly.

The goal is to build the finest theatre photography archive on the web.
